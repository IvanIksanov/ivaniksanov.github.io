Н@шли о#ибку?

Если вы нашли ошибку в материале или хотите добавить информацию к ответу на вопрос, то вы можете отправить сообщение Telegram-каналу QAtoDev. Это поможет другим qa-инженерам лучше подготовится к собеседованию. Если вы автор материала, то свяжитесь со мной для упоминания вашего канала или сервиса в QA песочнице.

Нужен новый API‑ключ

Похоже, текущий ключ не работает. Получите ключ в кабинете Groq и вставьте его ниже.

Открыть страницу создания ключа
  1. Нажмите Create API Key в кабинете Groq.
  2. В форме укажите любое имя ключа, например QAtoDev.
  3. Нажмите Create API Key, затем скопируйте созданный ключ и вставьте его сюда.
